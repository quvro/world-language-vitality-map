h2("3.4 复合字形：让一个符号编码五个维度")
para(
    "逐点视图存在一个固有上限：一个点只能承载一个变量。颜色编码濒危等级之后，"
    "描写深度、是否有维基版本、关注度这些信息就只能退到右侧卡片里，需要逐个点开才能看到。"
    "为了让多个维度**同时**出现在地图上，本设计引入复合字形（composite glyph）："
    "每门语言不再是一个圆点，而是一个由五个部件构成的符号。"
)

        ("中心点", "是否有维基百科版本", "实心 = 有，空心 = 无"),
        ("字形大小", "当月浏览量", "对数缩放"),
        ("外围刻度", "维基百科之外的其他维基项目数", "0–7 根短线"),
    ],
    ("部件", "编码的维度", "编码方式"),
    caption="表3  复合字形的五个部件与对应维度",
)
para(
    "这一设计的关键取舍在于**通道可关闭**。地图左下角浮着一个控制面板，五个部件可以单独开关。"
    "关掉的部件并不会消失，而是改用中性灰继续绘制——这样「关掉这个维度」的代价是看得见的："
    "地图会立刻灰掉一片，读者能直观地知道这一层信息本来承载了多少内容。"
    "如果让部件直接消失，视觉上更像渲染出错，反而失去了比较的意义。"
)

para(
    "实现上，字形通过 ECharts 的 custom series 绘制，在 renderItem 里用 api.coord 把经纬度换成像素坐标，"
    "再用绝对像素坐标画出环形、扇形、圆点和刻度线。由于世界视图下 renderItem 会被调用 2,662 次，"
    "颜色与半径全部在 computed 里一次算好，renderItem 只做取值，不在其中查表。"
)

h2("3.5 语言体检单：把六个维度换算成百分位")
para(
    "右侧详情卡给出的是绝对值，但绝对值无法比较——「月阅读 3,412 次」到底算多还是少？"
    "为此补充了语言体检单：把六个维度分别换算成该语言在全库中的百分位，"
    "读者立刻能判断它在 2,662 门语言里处于什么位置。"
)
para(
    "计算时有一个必须注意的细节：每个维度只在**拥有该数据的语言**中计算百分位。"
    "例如浏览量只有 267 门语言有，若以 2,662 为分母，几乎所有语言都会被判为「后 10%」，结论完全失真。"
    "图11 中 Deuri 的月阅读量显示「无数据」而不是「0」，正是这个处理的结果。"
)
figure("21-health", "图11  语言体检单：六个维度的百分位横条，用于识别「被研究得很透却几乎没人读」的语言")
para(
    "体检单真正的用途是暴露反差。单独看每个维度都还正常，并排放在一起才会发现某种形状："
    "描写深度和记录特征都在前 25%，而浏览量在后 25% 甚至没有数字入口。"
    "本设计据此加入了一条自动判据，当这种反差成立时直接给出提示。"
    "这恰好是「双重缺席」的反面证据——前文的视图都在呈现缺席，而这一处第一次把"
    "「明明被研究了却没人看」单独拎了出来。"
)

h2("3.6 大模型检索与问答：把检索留在前端")
para(
    "底部提问栏支持自然语言查询。整条链路被刻意拆成三段，并且把其中一段留在前端："
)

        ("意图解析", "把自然语言转成结构化筛选条件", "可由大模型完成，失败时退回本地规则解析器"),
        ("检索", "从数据中数出事实（分布、中位数、前几名）", "永远在前端，读取当前筛选结果"),
        ("措辞", "把事实写成通顺的句子", "可由大模型完成，无密钥时用本地模板合成"),
    ],
    ("阶段", "做什么", "在哪里做"),
    caption="表4  自然语言问答的三段职责划分",
)
para(
    "检索之所以必须留在前端，是为了保证答案里的每个数字与视图里的数字同源——"
    "两者都来自同一份筛选结果，因此不会出现「模型编了一个数」的情况。"
    "发给大模型的只有算好的证据包，它只负责把证据说成人话。"
    "这带来一个额外好处：没有配置密钥时，本地模板仍能根据同一份证据合成答案，整条链路不会中断，"
    "答辩现场也不必依赖网络。"
)
para(
    "在实测中还发现一个值得记录的细节。最初的证据包里只放了裸数字，模型便写出了"
    "「增长率中位数为 1.3374」和「均处于同一层级（lv=1）」这样的句子——"
    "问题不在模型，而在于数据里只有数字和字段名。修改方式不是加提示词去提醒它换算，"
    "而是在证据里就把话说完整：增加 medianPct=\"+133.7%\"、viewsText=\"645,562\" 这类已格式化的字段，"
    "并为濒危等级附上中文标签。修改后模型输出变为「增长率中位数为 +133.7%」「全部处于未濒危等级」，"
    "并自行补上了两条口径说明。"
)
figure("22-answer", "图12  大模型检索与回答面板：命中 136 门语言，答案由 deepseek-chat 基于前端算出的证据撰写")
para(
    "答案以独立抽屉呈现，包含问题原文、识别到的条件标签、命中规模、结论、要点、"

    "挤在一条细栏里读不清；抽屉可以随时关闭，也不遮挡地图。"
