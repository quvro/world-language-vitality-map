feat(figs): 用代码重画系统架构图与数据处理流程图

不用生图的原因：这两张是结构图，节点数固定、文字必须准确。
生图模型会把 157,736 写成 157.738、五个来源画成四个、连线接错层，
且改一个数字就要重生成一次。

做法：写 HTML + 无头浏览器截图（3200×2000）。
中文字体由系统渲染，绝对准确；排版用 CSS 精确控制；
缩略图直接 <img> 引用现有截图，用 object-fit 裁切成小图。

配色（低饱和，语义固定，两张图共用）：
  砖红 #B5564F = 输入   灰蓝 #4A6E8A = 处理
  苔绿 #6E8B6B = 输出   暖灰 #8C8880 = 中性   背景 #FAF8F4

图 A 系统架构（替换 01-mindmap）
  四层带状：数据来源 / 处理 / 应用 / 交互
  含五个来源卡片（带行数）、三方映射 pill、6 视图 + 3 功能 chips、
  右下三张视图缩略图

图 B 数据处理流程（替换论文图2）
  左到右：5 来源 → 主轴（抓取/清洗/聚合）→ 9 表 → 3 个 JSON → 一份契约
  右侧强调"实体对齐"（WALS 码 ↔ Glottocode ↔ ISO 639-3），
  并附记录缺口矩阵缩略图（15.0% 填充率）
